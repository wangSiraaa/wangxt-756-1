# 保障小组排班图

保障团队值班排班管理系统，支持排班编辑、冲突校验、关键岗位双人覆盖检查。

## 快速启动

```bash
npm install
npm run dev
```

默认端口：5173（如被占用自动递增）

## 功能检查步骤

### 1. 登录与角色差异
- 打开 http://localhost:5173/
- 分别用三个角色账号登录，观察顶部操作栏差异：
  - 组长：显示冲突按钮 + 请假审批入口
  - 组员：显示请假入口，无冲突按钮
  - 经理：显示冲突按钮 + 导出按钮，无编辑功能

### 2. 排班图
- 以组长登录后自动跳转排班图页面
- 横轴为日期（本周7天），纵轴为岗位（4个岗位，3个关键岗位）
- 每个日期列分早/午/晚三栏
- 格内显示值班人员头像+姓名
- 关键岗位行左侧有琥珀色圆点和"需双人覆盖"提示

### 3. 成员详情面板
- 点击排班格中的人员名，右侧滑出详情面板
- 展示头像、姓名、角色、状态、技能标签、排班历史、请假记录

### 4. 关键岗位双人覆盖校验
- 顶部冲突横幅显示当前冲突数量
- 点击冲突横幅或顶部冲突按钮打开冲突面板
- "双人覆盖"Tab 列出所有关键岗位覆盖不足的时段
- "请假冲突"Tab 列出请假成员仍被排入的时段

### 5. 排班编辑（组长专属）
- 在排班格中 hover 空白区域，右下角出现"+"按钮
- 点击弹出编辑弹窗，可添加/移除人员
- 若将请假成员排入班次，弹窗显示冲突警告
- 若关键岗位排班后不足2人，弹窗显示双人覆盖不足警告

### 6. 请假管理
- 组员点击顶部"请假"按钮进入请假页
- 选择日期、时段、填写原因后提交
- 组长点击"请假审批"进入审批页，可批准/驳回
- 批准请假后自动触发冲突校验

## 自动化检查

```bash
npm run smoke
```

检查内容：将请假成员放入班次，验证冲突提示是否出现。
